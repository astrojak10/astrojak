# Sitemap structure

The XML sitemap lists the public, canonical pages on `https://www.astrojak.in`:

| URL | Page |
| --- | --- |
| `/` | Consultation booking |
| `/home` | Kundali analysis and service information |
| `/plan` | Consultation plans |
| `/about` | About Acharya Narender Ji |
| `/kundli-matching` | Kundli matching service |
| `/kundali-analysis` | Kundali analysis service |

`/thank-you` is excluded because it is a transactional confirmation page and is disallowed in `robots.txt`. Privacy and refund information are in-page sections on `/home`, not separate URLs.

The sitemap omits `lastmod` because verified significant-change dates are unavailable. It also omits `changefreq` and `priority`, which Google ignores.

The `/shop` shortcut redirects customers to the ASTROJAK Shopify storefront at `https://shop.astrojak.in/`.
