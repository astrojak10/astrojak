1. Executive Summary

This report presents a comprehensive SEO audit of astrojak.in for a Astrology & Spiritual Advisory (Direct-to-Consumer / Online Professional Service) site, generated on October 31, 2026. Findings combine technical, content, schema, performance, visual, and search-readiness evidence as available.

  2. High: Missing AggregateRating in Schema for Google Star Snippets
  3. Medium: Missing Security & Cache Headers in Cloudflare Configuration
  4. Medium: LCP Hero Image Not Preloaded with High Priority
  5. Medium: Missing llms.txt and AI Crawler Content-Signal
Quick Wins:

  2. Fix H1 tags in home.html by downgrading policy headings from <h1> to <h2>/<h3>.
  3. Add fetchpriority='high' to <img src='/pandit.webp'> on both index.html and home.html.
  4. Add width and height attributes to review images to prevent Cumulative Layout Shift (CLS).
  5. Deploy a standard /llms.txt file summarizing Acharya Narender Ji's Vedic astrology services, pricing, and consultation process.

2. Audit Categories

2.1 Technical SEO

Score: 82/100

What Works

  • Clean robots.txt allowing all major search engine crawlers
  • Valid XML sitemap declared in robots.txt and accessible at /sitemap.xml
  • Proper canonical tags pointing to preferred https://www.astrojak.in/ URLs
  • Fast server-side static rendering via Cloudflare edge CDN
  • Zero crawl errors or infinite redirect loops

Findings

Missing Security Headers (HSTS, CSP, X-Content-Type-Options) Medium

The site does not emit HTTP Strict-Transport-Security (HSTS), X-Content-Type-Options: nosniff, or Referrer-Policy headers.

Recommendation: Configure response headers in Cloudflare Pages via _headers or Cloudflare Transform Rules.

Sitemap Lacks Image and Freshness Metadata Low

sitemap.xml lists only two URLs without image sitemap tags or automated lastmod update timestamps.

Recommendation: Add image tags for pandit.webp and review testimonials to assist Google Images indexation.

2.2 Content Quality & E-E-A-T

Score: 88/100

What Works

  • High information density score (0.86 - 1.0) with zero detectable AI boilerplate filler phrases
  • Strong first-person authority and credentials (Acharya Narender Ji, 20+ years experience, 1000+ consultations)
  • Clear pricing transparency (₹101 intro, ₹999 kundali, ₹1499 detailed) establishing commercial trust
  • Transparent refund policy and privacy safeguards published

Findings

Lack of Informational / Educational Content Architecture Medium

The site is currently a 2-page sales funnel with no blog or informational content targeting top-of-funnel queries (e.g. Manglik Dosh remedies, Sade Sati phases, Kundli matching rules).

Recommendation: Build a hub-and-spoke content cluster covering high-volume Vedic astrology informational queries.

Minor Typographic Spacing Errors in Section Headings Low

'Need Clear Answers?Ask Your Kundli' and 'Online VedicAstrology Consultation& Kundli Analysis' have missing spaces.

Recommendation: Add proper spacing between punctuation marks and words in heading tags.

2.3 On-Page SEO

Score: 78/100

What Works

  • Optimized homepage title tag (68 characters) with target keywords: Vedic Astrology Consultation, Kundali Analysis, ASTROJAK
  • Compelling meta description with pricing and booking call-to-action
  • Open Graph and Twitter Card tags configured with high-res 1200x630 share image
  • Clean, semantic section landmarks and accessible link anchors

Findings

Multiple H1 Tags on /home Page Critical

home.html contains 4 <h1> elements (hero title plus Refund, Privacy, and Terms headings).

Recommendation: Keep exactly one <h1> per page. Change policy section headings to <h2>.

Inverted Breadcrumb Hierarchy Medium

Breadcrumb schema defines /home as position 1 and / as position 2, which contradicts canonical site structure.

Recommendation: Set / as position 1 ('Home') and secondary pages as position 2.

2.4 Schema / Structured Data

Score: 84/100

What Works

  • Comprehensive JSON-LD with WebSite, ProfessionalService, OfferCatalog, and FAQPage
  • Detailed Offer entities with exact INR pricing and descriptions
  • FAQPage schema matching visible on-page accordion text for Google FAQ rich snippet eligibility

Findings

Omission of AggregateRating Schema High

Visual 4.98 rating is not translated into Schema.org AggregateRating markup.

Recommendation: Nest aggregateRating under ProfessionalService with ratingValue: 4.98 and reviewCount: 1000.

Missing Physical Address or OnlineService Distinction Low

ProfessionalService schema lacks postalAddress, which Google prefers for local/service entities.

Recommendation: Add PostalAddress with addressCountry: IN or specify OnlineBusiness service types.

2.5 Performance (Core Web Vitals)

Score: 80/100

What Works

  • Fully inlined, critical CSS avoiding external render-blocking stylesheets
  • Zero client-side JavaScript rendering requirement (pure static HTML)
  • Modern WebP image format used for primary hero photo
  • Native loading='lazy' configured on below-the-fold testimonial images

Findings

Hero LCP Image Not Priority-Loaded Medium

The main hero image (/pandit.webp) is rendered without fetchpriority='high', postponing LCP paint.

Recommendation: Add fetchpriority='high' and <link rel='preload' as='image' href='/pandit.webp'> in <head>.

Missing Speculation Rules for Instant Navigation Low

Navigation between / and /home requires standard HTTP roundtrip instead of instant prerender.

Recommendation: Include a Speculation Rules script block to prerender /home upon link hover.

2.6 AI Search Readiness (GEO)

Score: 74/100

What Works

  • Zero WAF blocking: GPTBot, ClaudeBot, PerplexityBot, and OAI-SearchBot all return 200 OK
  • Clean server-rendered semantic HTML accessible without JavaScript execution
  • Clear pricing and service definitions readily extractable by LLMs and answer engines

Findings

Missing /llms.txt and /llms-full.txt Discovery Files Medium

AI agents and search crawlers checking for /llms.txt receive HTTP 404.

Recommendation: Publish a clean /llms.txt documenting services, pricing, Acharya's credentials, and FAQs in Markdown.

No Content-Signal Policy Declared Low

No Content-Signal HTTP header or robots.txt line declaring AI scraping preferences.

Recommendation: Add 'Content-Signal: search=yes, ai-input=yes, ai-train=no' to robots.txt.

2.7 Images & Visual Layout

Score: 82/100

What Works

  • Mobile-responsive layout verified across desktop, laptop, tablet, and mobile viewports
  • Touch targets meet accessibility guidelines (>44px)
  • Hero portrait has explicit width and height dimensions preventing CLS

Findings

Primary CTA Button Located Below Initial Mobile Fold Medium

Visual analysis indicates the primary reservation CTA requires scrolling on smaller screens.

Recommendation: Add a sticky mobile booking bar or elevate the primary CTA above the fold on mobile.

Review Testimonial Images Use JPG Format Low

Review screenshots are uncompressed JPG files without explicit width/height dimensions.

Recommendation: Convert to WebP and add explicit width/height to avoid cumulative layout shift.
